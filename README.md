# Pixel Zombie Survivor

2D pixel-art top-down шутер про выживание среди зомби: волны врагов, магазин во время боя,
покупка оружия, построек и расходников. Весь контент (спрайты, кадры анимации, префабы,
ScriptableObject-ассеты, сцена) генерируется редакторным скриптом — внешние ассеты не нужны.

- Unity: **6000.6.7f1** (Unity 6), URP не требуется — обычный 2D-рендер
- Ввод: legacy Input Manager (`Input.GetAxisRaw`, `Input.GetMouseButton`)
- UI: UGUI (`UnityEngine.UI`), собирается в рантайме кодом, без TextMeshPro
- Namespace: `PixelZombieSurvivor`

## Быстрый старт

1. Откройте папку `PixelZombieSurvivor` через Unity Hub (версия 6000.6.7f1).
2. Дождитесь компиляции скриптов.
3. Меню **Tools ▸ Pixel Zombie Survivor ▸ Build Demo Project** — генерирует арт, данные,
   префабы, сцену `Assets/PixelZombieSurvivor/Scenes/Arena.unity` и прописывает её в Build Settings.
4. Откройте сцену `Arena` и нажмите **Play**.

Если сцена пустая или ассеты удалены — просто повторите шаг 3: генератор пересоздаёт всё
с нуля (существующие файлы перезаписываются).

## Управление

| Действие | Клавиша |
| --- | --- |
| Движение | WASD / стрелки |
| Прицел | мышь |
| Стрельба | ЛКМ (удержание — автоматический огонь) |
| Перезарядка | R |
| Смена оружия | 1–9 или колесо мыши |
| Рывок (с откатом ~2.2 с) | Space |
| Пауза / продолжить | Esc |
| Магазин | TAB |
| Начать следующую волну | кнопка «НАЧАТЬ ВОЛНУ» в передышке |
| Постройка: подтвердить | ЛКМ |
| Постройка: отмена | ПКМ / Esc |
| Полный экран (в сборке) | F11 или Alt+Enter |
| Рестарт после смерти | кнопка на экране поражения |

Игра **не ставится на паузу** при открытом магазине — покупать можно и во время волны.
Esc в магазине или в режиме размещения закрывает/отменяет его, а не ставит игру на паузу.

## Геймплей

- Волны идут одна за другой; с каждой волной растут количество, здоровье, урон и скорость зомби,
  а также награда за убийство. Рост специально сделан пологим, чтобы после 10-й волны оставалось
  место для манёвра (см. «Экономика и баланс»).
- Между волнами игра ждёт игрока: магазин открыт, а новая волна стартует только по кнопке
  «НАЧАТЬ ВОЛНУ». Отсчёт больше не запускается автоматически.
- Зомби появляются из 12 точек спавна по периметру арены и идут к игроку или к постройкам.
- Монеты выпадают из зомби и подбираются автоматически (магнит + сбор в конце волны).
- Игрок: здоровье, инвентарь оружия, смена оружия на лету, короткий рывок Space с неуязвимостью
  на время рывка, покраснение тела при получении урона.
- Постройки: турель (стреляет сама), генератор денег (пассивный доход), ремонтная станция
  (лечит игрока и постройки рядом). Оплата списывается только при подтверждении установки.
- Расходники: аптечка (лечение) и ящик патронов (пополнение запаса).
- Звук процедурный: выстрелы, подбор монеты, урон, рывок и старт волны синтезируются в рантайме
  (`AudioService`), аудиофайлов в проекте нет.

### Бафы после 10-й волны

После завершения 10-й волны (и далее после каждой 5-й) игра предлагает выбрать одно усиление:

| Баф | Эффект |
| --- | --- |
| Вампиризм | +3 HP за каждое убийство, складывается по уровням |
| Скорость | +12% к скорости движения за уровень |
| Щит | +30 щита; восстанавливается в начале каждой волны |

Выбор показывается поверх HUD и блокирует старт следующей волны, пока игрок не выберет баф.

## Экономика и баланс

| Параметр | Значение |
| --- | --- |
| Стартовый баланс | 300 монет |
| Монеты за зомби | Ходок 10, Бегун 9, Громила 35 |
| Рост награды за волну | +15% за каждую следующую волну |
| Ящик патронов | 55 монет → +150 патронов всем купленным стволам |
| Аптечка | 100 монет → +50 HP |
| Запас патронов при старте | пистолет 120, SMG 150, AK-47/M4A1 180, LMG 260 |
| Цены оружия | SMG 300, AK-47 900, M4A1 1250, LMG 2100 |
| Постройки | турель 550, раздатчик денег 400, ремонтный модуль 500 |

Награда за волну считается как `reward × (1 + 0.15 × (волна − 1))`, поэтому на поздних
волнах монеты приходят быстрее. Всё это настраивается в `Data/WaveSettings.asset`
(прирост награды) и в карточках зомби/оружия/расходников.

### Кривая сложности

| Параметр | Значение |
| --- | --- |
| Зомби в волне | 6 + 2 за каждую следующую волну (максимум 85) |
| Одновременно живых | 14 (+1 каждые 3 волны, максимум 24) |
| Рост здоровья | +17% за волну |
| Рост урона | +10% за волну |
| Рост скорости | +3% за волну, не более +35% |
| Скорость зомби | Ходок 2.0, Бегун 3.4, Громила 1.5 (игрок 5.5 + рывок ×3.2) |

Числа задаются в `DemoProjectBuilder.ConfigureWaveSettings` и пересоздаются при
**Tools ▸ Pixel Zombie Survivor ▸ Build Demo Project**. Их же можно править прямо
в `Data/WaveSettings.asset`.

## Полноэкранный режим

**В редакторе (пока играете через Play).** Окно Game рендерится внутри Unity, поэтому
`Screen.SetResolution` на него не действует. Варианты:

1. Наведите курсор на окно **Game** и нажмите **Shift+Space** — оно развернётся на весь экран
   редактора (повторное нажатие вернёт обратно). Самый быстрый способ.
2. В панели **Game** включите кнопку **Maximize On Play** (иконка в тулбаре Game view) —
   тогда при каждом нажатии Play окно игры сразу разворачивается.
3. В тулбаре редактора рядом с **▶** есть кнопка **Play Maximized** — запуск сразу в
   развёрнутом Game view.

**В собранной игре.** Проект уже настроен на `FullScreenWindow` (Player Settings ▸
Resolution and Presentation), так что билд стартует во весь экран. Переключение на лету —
**F11** или **Alt+Enter** (`FullscreenController` устанавливается автоматически в рантайме,
в сцене ничего подключать не нужно). Окно в оконном режиме — 1280×720, размер меняется
в инспекторе компонента `FullscreenController`.

Сборка: **File ▸ Build Settings ▸ Build** (сцена `Arena` уже в списке).

### Точки расширения

- **Новое оружие** — создайте `WeaponDataSO` (Create ▸ Pixel Zombie Survivor ▸ Weapon Data),
  добавьте его в `GameDatabaseSO.Weapons`. Магазин и хоткеи 1–9 подхватят его автоматически.
- **Новый тип зомби** — `ZombieDataSO` + запись в `GameDatabaseSO.Zombies`; модель волн
  выбирает типы по `WaveSettingsSO`.
- **Баланс волн** — `Assets/PixelZombieSurvivor/Data/WaveSettings.asset`: стартовое количество,
  прирост за волну, множители HP/урона/скорости, награда. Волны стартуют вручную, поэтому
  «интервал» между ними не используется.
- **Новая постройка** — `BuildingDataSO` (префаб, цена, радиус, параметры) + запись в базу.

## Анимация

Анимация покадровая, без Animator Controller — так пул объектов и переиспользование префабов
остаются простыми.

- `PixelArtGenerator` собирает кадры из одной символьной карты: тело + варианты ног + смещение
  верхней части корпуса. Игрок: 2 кадра покоя, 8 кадров ходьбы. Каждый тип зомби:
  8 кадров ходьбы и 6 кадров атаки.
- `SpriteAnimator` (`Scripts/Core`) — лёгкий проигрыватель клипов: массив `Sprite[]`, FPS,
  зацикливание, событие `Completed` для не зацикленных клипов.
- `PlayerVisualController` переключает покой/ходьбу по фактической скорости `Rigidbody2D`.
- `Zombie` держит клип ходьбы, ставит его на паузу в стойке и проигрывает клип атаки при ударе,
  возвращаясь к ходьбе по `Completed`. Кадры и FPS берутся из `ZombieDataSO`
  (`WalkFrames`, `AttackFrames`, `WalkFramesPerSecond`, `AttackFramesPerSecond`).

Чтобы заменить арт на свой: положите кадры в `Art/` и через инспектор `ZombieDataSO` /
`PlayerVisualController` укажите массивы кадров (или расширьте `DemoProjectBuilder`).

## Автотест

`SmokeTestRunner` проверяет сцену в edit mode (наличие менеджеров, префабов, ассетов,
кадров анимации) и в play mode (UI, магазин, стрельба и движение снарядов, пауза, рывок,
выбор бафа, урон/щит, постройка, ручной старт волны).

```
Unity.exe -batchmode ^
  -projectPath "<путь>\PixelZombieSurvivor" ^
  -executeMethod PixelZombieSurvivor.Editor.SmokeTestRunner.Run ^
  -logFile "pzs_smoke.log"
```

Отчёт пишется в `%TEMP%\opencode\pzs_smoke.txt`. Процесс завершается сам — `-quit` не нужен.

## Заметки

- `ProjectAutoSetup` пропускает автогенерацию в batch mode, чтобы сборка из CI не пересоздавала ассеты.
- Спрайты импортируются с point-фильтрацией, PPU 16, без сжатия.
- Звук синтезируется процедурно в `AudioService` (короткие PCM-клипы), громкость — в инспекторе.
